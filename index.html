Everything you need

Browse, query, and manage your MongoDB databases with a clean native interface.

Connection Management

Save and organize connection profiles. Supports host/port, connection strings, SCRAM-SHA-256, and TLS.

Query Builder

Write filters, sort, and project with instant results. Query any collection with the full power of MongoDB's query language.

Document Editing

View, edit, insert, delete, and duplicate documents inline. Changes are saved directly to MongoDB.

Collection Browser

Navigate databases and collections with stats at a glance. See document counts, storage size, and index info.

Index Viewer

List all indexes with their keys, uniqueness constraints, and sizes. Understand your data access patterns.

Dark & Light Mode

Follows your system appearance automatically. A warm cream palette in light mode, deep charcoal in dark.

Built different

Mango compiles TypeScript to native machine code using Perry. No web views, no garbage collection, no runtime bloat.
